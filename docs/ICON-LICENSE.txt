The SVG geometry in src/icons.ts is copied from these official Lucide SVGs.
Only the shared wrapper is adapted: 20x20 display size, 24x24 viewBox,
1.6 stroke width, currentColor, rounded caps and joins, and accessibility
attributes. No runtime icon dependency is used. Unknown names use file-text.
