FEATURES INCLUDED IN ALPHA 02

Tools for reading research papers.

Preview references, compare passages, explore citations and save notes. Here is what each tool does.

01 / REFERENCE PREVIEWS

Equations, figures, tables & citations

Press F to preview a reference without leaving your paragraph. Two-column PDFs fit the target column; scroll the preview for context or jump to its source.

Try preview with mouse & keyboard ↗
02 / THEMES

23 themes with custom palettes

Choose light, dark or terminal-inspired themes. Set paper and text colors, replace diagram colors, or turn recoloring off for color-critical figures.

Try themes with mouse & keyboard ↗
03 / KEYBOARD & HISTORY

Navigate, search & return

Use j/k to scroll, / to search and : to find commands. Reading history, bookmarks and saved positions help you return after a reference jump. Press g then 2 for two-page view.

jkmove/find:commands
Try the keyboard controls ↗
04 / NOTES & EXPORT

Local notes & portable backups

Save quoted passages and page-linked notes, export cited Markdown, or back up and restore a notebook sidecar. Notes stay separate from the original PDF; they are not embedded PDF annotations.

Try the reader ↗
05 / SPLIT VIEW

Keep two passages in view

Pin a preview beside the document, resize the pane, and navigate it independently. Compare a derivation with its definition or a result with the table it references.

Shift P pin / unpin · g P full-page preview

06 / CITATION NETWORKS

Explore the surrounding literature

Find the papers a work cites and the papers that cite it. Explore 1–3 hops in a graph or accessible list, inspect paper details, and open indexed or publisher-discovered PDFs.

g c citation map

Uses OpenAlex metadata and bounded samples. Node size reflects citation rate, not scientific quality. Publisher access may require institutional sign-in.

07 / LOCAL FILES

Browse folders from the keyboard

Press o for a three-column browser showing the parent folder, current files and selection preview. Use arrows or h/j/k/l to navigate, / to filter and Enter to open a PDF.

Initial folder access requires the system permission picker. Chromium can remember granted folders; fallback imports are session-only.

08 / LOCAL PROCESSING

Your PDFs stay on your device

Rendering, text extraction, in-document reference lookup and notes run in your browser. No account, document-upload service or analytics scripts are required.

Remote PDFs contact their source. Citation maps send paper metadata to OpenAlex; publisher discovery contacts the selected publisher.

SUPPORT & LIMITATIONS

Questions about Pipit

Does opening a PDF save it to Downloads?

Eligible top-level PDF links open inline in the Chromium and Firefox extensions. PDF bytes still have to be fetched, and your browser may cache them. Save an original copy only when you choose Download. Safari uses explicit opening rather than automatic interception.

What’s included in the alpha?

Reference previews, split views, keyboard navigation, reading history, two-page view, 23 themes, local notes, folder browsing and broader OpenAlex citation maps. Text/object detection is heuristic; scans need external OCR. Citation maps are bounded samples, and publisher PDF access is not guaranteed.

What happens to my existing Paperterm data?

Pipit is the new name for Paperterm. Existing storage keys and Firefox extension identity are retained. Reload the existing unpacked extension in the same folder/profile to retain its identity. A new extension ID, profile, or website origin has separate local data. Export important notes before changing installations.

Can I trust scientific figures in a recolored theme?

Recoloring intentionally changes images as well as text. Use the original-color toggle whenever a plot’s precise colors matter. The alpha still needs broader validation on very large files, unusual fonts, and complex documents.
