BEFORE YOU TAKE FLIGHT

A few good questions.

Does opening a PDF save it to Downloads?

Eligible top-level PDF links open inline in the Chromium and Firefox extensions. PDF bytes still have to be fetched, and your browser may cache them. Save an original copy only when you choose Download. Safari uses explicit opening rather than automatic interception.

What’s included in the alpha?

Keyboard navigation, equation and citation previews, reading history, two-page view, themes, a local notebook, and a citation graph within the current PDF. Text lookup is heuristic. Scans need OCR elsewhere; author–year citations and cross-paper graphs aren’t supported.

What happens to my existing Paperterm data?

Pipit is the new name for Paperterm. Existing storage keys and Firefox extension identity are retained. Reload the existing unpacked extension in the same folder/profile to retain its identity. A new extension ID, profile, or website origin has separate local data. Export important notes before changing installations.

Can I trust scientific figures in a recolored theme?

Recoloring intentionally changes images as well as text. Use the original-color toggle whenever a plot’s precise colors matter. The alpha still needs broader validation on very large files, unusual fonts, and complex documents.

Where can I report a problem?

For this initial alpha, send your maintainer the browser/version, operating system, reproduction steps, and a non-sensitive sample if possible. The development repository is private; there is no public issue tracker or store listing yet.
